# La Traversée du regard

Prototype des expériences numériques d’Éditions LÀ.

- Jour 1 — S’arrêter : `/`
- Jour 2 — Nommer : `/jour-2/`
- Jour 3 — Commenter : `/jour-3/`

## Tester localement

```bash
python3 -m http.server 8080
```

Puis ouvrir `http://localhost:8080`.

## Caractéristiques

- huit écrans navigables au clavier et au toucher ;
- expérience d’écoute chronométrée de trois minutes ;
- aucune collecte de données ;
- aucun cookie ;
- aucune dépendance externe ;
- compatible avec GitHub Pages.

## Publication

Le site peut être publié directement avec GitHub Pages depuis la branche principale du dépôt.
